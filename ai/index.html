🧠 How these tools work without an API key

AI Grammar uses a small language model (WebLLM) that runs directly in your browser using WebAssembly. AI Transcribe uses Whisper.js — a JavaScript port of OpenAI Whisper — which also runs locally. The first load downloads the model (~40–150 MB, cached for future visits). After that, everything works offline. No API key, no cost per request, no data leaving your device.
